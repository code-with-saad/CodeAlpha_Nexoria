## How to add screenshots

Run the app locally (`npm run dev` in /client + `npm start` in /server), then capture these pages and save them here:

| Filename | URL / Steps |
|---|---|
| `homepage.png` | http://localhost:5173 |
| `products.png` | http://localhost:5173/products |
| `admin.png` | http://localhost:5173/admin (Overview tab) |
| `admin_analytics.png` | http://localhost:5173/admin (Analytics tab) |
| `dark_mode.png` | Homepage with dark mode toggled on |
| `cart.png` | Any product page -> Add to Cart -> open cart drawer |

You can use browser DevTools -> "Capture screenshot", ShareX, or any screen capture tool.
